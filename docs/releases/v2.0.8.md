# Tigris 2.0.8

## Android 9 / 10 update compatibility fix

- Fixes [Issue #38](https://github.com/lesnolie/Tigris/issues/38) / [PR #39](https://github.com/lesnolie/Tigris/pull/39): the Software Updates screen could incorrectly report **“缺少安装包签名 / Missing APK signature”** when installing the official MiracastReceiver on Sony BRAVIA VH1 (Android 9 / API 28), even though the package had a valid matching signing certificate.
- On Android 9 / 10, if the archive signer is missing from `GET_SIGNING_CERTIFICATES`, retry the legacy `GET_SIGNATURES` parser **for that same package**. For Android 11+, modern verification is unchanged.
- **No security verification is disabled:** Tigris still validates the APK identity and minimum OS requirements, refuses downgrades, checks the pinned MiracastReceiver signing certificate SHA-256 for first-time installs, and requires matching installed signing certificates for upgrades.
- Six new JVM regression scenarios cover the legacy fallback, signer precedence, wrong signer, missing signer and no fallback on newer Android.

## Installation

- **Standard APK:** `Tigris-v2.0.8.apk`
- **Guard APK (TCL / 雷鸟等兼容路线):** `Tigris-guard-v2.0.8.apk`
- **Checksums:** `SHA256SUMS-v2.0.8.txt`

Both APKs keep `com.leslie.tvhome`, increment `versionCode` to 14 and **must be built with the same stable signing key as v2.0.7**. Existing signed installations can normally update in place without uninstalling or erasing their configuration. Use the appropriate variant for your TV; **do not uninstall the original launcher or Tigris to force an update**.

## Verification and limitations

The fix passed the Android Standard/Guard JVM tests, installer safety checks, release builds and Android Lint in PR #39. The **v2.0.8 signed-release workflow** independently rechecks the APK package ID, `versionName`, and original stable signing certificate fingerprint before publication. APK installation on an actual Sony BRAVIA VH1 Android 9 device **has not yet been re-tested with v2.0.8**. The reporter is invited to test Software Updates → MiracastReceiver after upgrading and share results in [#38](https://github.com/lesnolie/Tigris/issues/38).

This Android version does not change or publish the separate LG webOS preview; it does not introduce webOS Home-key interception.

## 中文简述

修复 Android 9 / 10 上「软件更新 → MiracastReceiver 投屏」误报 **“缺少安装包签名”** 的问题：旧版 Android 读取未安装 APK 的 `signingInfo` 可能为空。现在仅在 Android 9/10 必要时重新读取 `GET_SIGNATURES`，**仍校验完整包名和官方签名 SHA-256，绝不跳过安全检查**。Android 11 及以上保持原来的新接口验证方式。

正式版保留标准版与 Guard 守护版，继续使用既有稳定签名。Sony VH1 上的更新安装还需要用户实机复测；未经实测不作兼容性保证。
