- 安装器与手动 / AI 安装共用实际 HOME 检查：从其他界面开始，连续观察稳定前台；解析成功不再等于接管成功。

- LG webOS 源码预览补全 SSH 密钥配对和设备信息检查；修复设置/弹窗方向导航及超过 8 个应用时输入源不可达的问题。

## 发布边界

Android 标准版和 Guard 版继续使用 `com.leslie.tvhome`，保留配置，正式制品必须由现有稳定签名流水线生成。不要将本地 debug-key 签名的 Release 构建当作正式升级包分发。

APK 安装、实体 Home、待机唤醒、重启分别验收。软件测试不能代表所有型号/固件真机验证。LG 仍为普通应用源码预览，没有稳定 IPK 或 Home Helper，不承诺替换原厂 Home。

完整规则：[安装兼容性](../installation-compatibility.md)。

## Redmi / MIUI feedback follow-up

- Wake animation: prepare a black cover when the screen turns off, then consume the pending animation before Home resumes drawing. A late screen-on broadcast no longer starts a second animation. The wake delay controls playback behind the cover, not when the cover appears.
- Memory cleanup: when Android restarts the sticky keeper service, check once after five seconds for an enabled but unbound Home Guard and use the existing guarded recovery path. This does not force Home takeover without a stock HOME window event.
- These are code-level fixes, not a Redmi X50 hardware certification. A firmware-rendered task snapshot or stock-launcher flash may remain. If MIUI prevents the entire process from restarting, Tigris cannot repair itself while stopped; no aggressive restart loop or firmware bypass is added.
