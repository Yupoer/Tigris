# Tigris 2.0.7

**本版未做实机测试。自动化测试和构建通过不等于红米 X50 / MIUI 或其他电视实测通过。**

- 安装器与手动 / AI 安装共用实际 HOME 检查：从其他界面开始，连续观察稳定前台；解析成功不再等于接管成功。
- 所有品牌先验证，实际失败后再配置守护；无法验证时停止并解释，不猜测白名单。原桌面恢复未通过时禁止继续卸载。
- 所有 Android 电视提供“安装与 Home 检查”和桌面守护入口，明确显示权限、服务与实测结果的区别。
- 官网和 README 提供遥控器 / U 盘及电脑入口、品牌排障与四项验收；修复 Windows 注册/截图命令和恢复流程冲突。
- LG webOS 源码预览补全 SSH 密钥配对和设备信息检查；修复设置/弹窗方向导航及超过 8 个应用时输入源不可达的问题。

## 发布边界

Android 标准版和 Guard 版继续使用 `com.leslie.tvhome`，保留配置，正式制品必须由现有稳定签名流水线生成。不要将本地 debug-key 签名的 Release 构建当作正式升级包分发。

APK 安装、实体 Home、待机唤醒、重启分别验收。软件测试不能代表所有型号/固件真机验证。LG 仍为普通应用源码预览，没有稳定 IPK 或 Home Helper，不承诺替换原厂 Home。

完整规则：[安装兼容性](https://github.com/lesnolie/Tigris/blob/main/docs/installation-compatibility.md)。

## 红米 X50 / MIUI：邀请对应电视用户测试

- 待机唤醒动画：提前准备黑色遮罩，减少动画前 Tigris 主页闪现；延迟设置控制遮罩后的播放时间。系统快照或原厂桌面的闪现不保证消除。
- 长按 Home 清理内存：系统允许进程恢复时，补一次已启用但未绑定的守护服务检查。若 MIUI 阻止整个进程恢复，应用无法自救；不加入强行绕过。

请红米 X50 / MIUI，以及遇到相同问题的小米 / Redmi 用户协助验证：

1. 从其他应用按实体 Home，是否进入 Tigris。
2. 待机后唤醒，是否先闪主页、动画是否播放完整；分别记录动画模式和等待时间。
3. 长按 Home 使用系统清理内存后，守护能否恢复、约需多久；再按 Home 是否有效。
4. 在方便且确认可重启时，检查重启后是否保持。未测试就标为未测试。

请在 [GitHub Issues](https://github.com/lesnolie/Tigris/issues) 提供电视型号、MIUI / 固件版本、标准版或 Guard 版、以上每项结果。闪屏请说明是 Tigris 还是原厂桌面，方便时附短视频。无需关闭或卸载原厂桌面。
