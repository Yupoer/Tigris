## 发布操作与边界

先将代码与配套检查器合并，再部署官网，避免新页面引用尚未合并的 `main/tools/check-install.py`。随后使用已有稳定签名 Release 工作流发布 `v2.0.7`；不要上传本地 debug-key 签名的 Release APK 作为正式升级包。

本轮未对电视执行安装、授权、Home、待机或重启。各品牌、具体固件的实体遥控器/唤醒/重启测试仍待实测，界面和文档已明确“未验证”。LG 仅为普通应用源码预览，尚无稳定 IPK/Home Helper，不能宣称接管 LG Home。

源码和发布流水线已准备；公开发布、官网部署、稳定签名制品及上述真机项目不在本轮本地验证结果之内。
