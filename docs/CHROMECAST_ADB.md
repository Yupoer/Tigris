# Chromecast 的本機偵錯

Android 11 以上的「無線偵錯」使用配對金鑰與每次可能不同的連線埠。Tigris 先尋找這台裝置自己的無線偵錯服務並嘗試加密連線；舊版 Android TV 仍可使用已授權的 `127.0.0.1:5555`。Mac 與電視不必維持相同 IP 或固定埠。

首次設定：在 Tigris「主畫面設定 → 本機偵錯授權」掃描 QR 碼，讓手機留在配對頁；再到 Chromecast「設定 → 系統 → 開發人員選項 → 無線偵錯 → 使用配對碼配對裝置」。保持電視的配對碼視窗開啟，在手機輸入六位數代碼。Tigris 會自動尋找配對埠並執行連線測試。配對金鑰存於 Chromecast 的 Android Keystore，不會上傳到手機或雲端。

成功後，「保持無線偵錯開啟」會嘗試在重開機或系統關閉偵錯後恢復它。此選項需要 Tigris 已取得 `WRITE_SECURE_SETTINGS`，而且仍受 Chromecast 韌體與目前 Wi-Fi 信任狀態限制。畫面上的「測試連線」會再次確認實際可用，不能只憑已配對的記錄認定連線成功。啟用無線偵錯後，同一網路會看見此裝置的偵錯服務，但只有已配對金鑰能連入。

更新 Tigris 請使用相同套件名稱及同一把簽署金鑰，以覆蓋安裝保留 App 順序、隱藏清單、壁紙選擇及其他設定。不要先卸載或執行 `pm clear`。Android 若偵測到簽署金鑰不同會拒絕更新，而不會自動清除資料。

本機偵錯與信號源是不同功能。外接 Chromecast 沒有 TCL 電視的 HDMI 輸入清單；即使偵錯連線成功，也無法從 Chromecast 的 `TvInputManager` 讀到電視本身的插孔。
