# Chromecast 的本機偵錯

Tigris 的「關機」與深度釋放記憶體功能會由 App 連到電視自己的 `127.0.0.1:5555`。這與 Android「無線偵錯」顯示的動態配對埠、連線埠不同。首頁、Google TV 入口與 AirPlay 不需要本機偵錯。

這台 Chromecast 在重開機後會關閉傳統 ADB `5555`。若 Tigris 顯示「未授權，按確認鍵重試」，先在電視開啟「設定 → 系統 → 開發人員選項 → 無線偵錯」。電腦若已和電視配對過，不必再抄通訊埠；在 repo 根目錄執行：

```sh
TV=192.168.0.43 bash tools/enable-local-adb.sh
```

腳本會依 IP 尋找目前的無線偵錯連線埠，再將 ADB 切換到 `5555`。回到 Tigris「主畫面設定 → 本機偵錯授權」重試一次，並在 Android 授權視窗核准 Tigris 的金鑰。`5555` 會讓同一區域網路看得到需金鑰授權的 ADB 入口；不需要關機與清理功能時，可以保持這項授權未開啟。

**這不是跨重開機的固定埠保證。** 實測重開後 `5555` 會關閉；若無線偵錯也關閉，電腦無法自行重新開啟，須先在電視打開。Tigris 自動進首頁與這個埠無關。
